# Day 01 - Flowchart & Pseudocode

**Date:** 07/10/2026

## Topics Covered

Today I started my DSA journey with the basics of problem solving using **Flowcharts** and **Pseudocode**.

### 1. Flowchart

Learned the basic components of a flowchart:

- Start / Exit
- Input / Output
- Process
- Arrow / Flow line
- Decision

I practiced creating flowcharts to represent the logic of different problems.

### 2. Pseudocode

Learned how to write the step-by-step logic of a problem in a simple and understandable form before implementing it in a programming language.

## Problems Practiced

I practiced the following problems using **Pseudocode and Flowcharts**:

1. Sum of two numbers
2. Area of a square
3. Minimum of two numbers
4. Check whether a number is Odd or Even
5. Sum of numbers from 1 to N
6. Check whether a number is Prime or not
7. Calculate Simple Interest
8. Maximum of two numbers
9. Calculate Factorial of a number

## Learning Outcome

Today I learned how to break a problem into smaller logical steps and represent the solution using **Pseudocode** and **Flowcharts**.

This helped me understand the logic of a problem before writing the actual program.
