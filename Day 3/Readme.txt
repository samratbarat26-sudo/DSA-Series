# Day 03 – Conditional Statements and Loops

## Topics Covered

- Conditional Statements
- Ternary Operator
- `for` Loop
- `while` Loop
- `do-while` Loop
- Nested Loops

## Practice Problems

### Conditional Statements
1. Voter Eligibility Check
2. Odd or Even Number Check
3. Grade Check

### Loops
1. Print Numbers from 1 to 5 using `for` and `while` loops.
2. Print Numbers from 1 to `n`.
3. Calculate the Sum of All Odd Numbers from 1 to `n`.
4. Check Whether a Number Is Prime or Not.

### Nested Loops
1. Print a 5 × 5 Star Pattern.
2. Calculate the Sum of Numbers from 1 to `n` That Are Divisible by 3.
3. Calculate the Factorial of a Number `n`.

## 🎯 Learning Goals

- Understand conditional statements and the ternary operator.
- Learn how to use different types of loops.
- Practice number-based problems using loops.
- Understand nested loops and their execution.
- Improve logical thinking and problem-solving skills.
